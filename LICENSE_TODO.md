# Before publishing: resolve licensing

This repo currently has NO LICENSE file. Do not add one (or claim MIT, as an
earlier draft of this README did) until you've confirmed where the 11 skill
files under each subfolder originally came from and whether you have the
right to redistribute them publicly:

- If you or your team wrote them from scratch: you can license them however
  you like (MIT is a reasonable default for this kind of content).
- If they came from a paid marketplace, a vendor's org catalog, or someone
  else's open-source repo: check that source's own license/ToS before
  republishing. Some marketplaces explicitly prohibit redistribution even of
  installed content.

Once resolved, delete this file and add a proper LICENSE.
